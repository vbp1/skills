TECHNICAL APPROACH

Reuse the shared query builder from #003: the export runs the same query the page already runs, with paging removed and a hard row cap applied. Serialization is a pure function under unit tests; the route only streams what it returns.

Export control→ GET /reports/:id/export→ query builder (#003)→ CSV stream
